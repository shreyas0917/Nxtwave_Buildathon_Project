FOR HACKATHON DEMO - GET RUNNING IN 5 MINUTES!

STEP 1: BACKEND SETUP
----------------------
1. Open Terminal/Command Prompt
2. cd backend
3. python -m venv venv
4. venv\Scripts\activate  (Windows) OR source venv/bin/activate (Linux/Mac)
5. python -m pip install --upgrade pip  (IMPORTANT: Upgrade pip first!)
6. pip install -r requirements.txt
7. python init_models.py
8. python start.py

NOTE: Make sure virtual environment is activated (you should see (venv) in prompt)

✅ Backend running at: http://localhost:8000
✅ API Docs at: http://localhost:8000/docs

STEP 2: FRONTEND SETUP (NEW TERMINAL)
--------------------------------------
1. cd frontend
2. npm install
3. npm run dev

✅ Frontend running at: http://localhost:3000

DEMO CHECKLIST:
---------------
□ Backend running (port 8000)
□ Frontend running (port 3000)
□ Open http://localhost:3000 in browser
□ Test Breed ID page
□ Test Risk Assessment page
□ Test AI Advisor page
□ Test offline mode (disconnect internet)

TROUBLESHOOTING:
----------------
- Port in use? Change port in start.py (backend) or vite.config.js (frontend)
- Models not found? Run: python init_models.py
- Import errors? Check: pip install -r requirements.txt
- CORS errors? Make sure backend is running first
